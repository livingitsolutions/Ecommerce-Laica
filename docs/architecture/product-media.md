# Product images and video

MediaGallery is shared by product details and the offline live studio. It sorts by position, filters shared plus selected-variant media, renders thumbnails, supports touch swipes and left/right keyboard navigation, has an image zoom toggle and a fullscreen-sized native dialog with contained image/video viewing. Native video controls use preload=none, poster images and descriptive labels. Images load lazily except the homepage hero. Dialogs use native modal focus containment and restore focus to the invoking control.

The second sample image is a higher-resolution version of the same photograph, not a claimed alternate angle. The sample video is a generic CC0 flower clip from MDN and is explicitly labeled as unrelated playback demonstration. Unsplash photographs illustrate fictional merchandise and do not prove actual product appearance. No upload, processing, delete endpoint, adaptive streaming or production CDN optimization is implemented. In-browser dialog viewing does not invoke the operating system fullscreen API. Image load failures currently use browser fallback/alt text; a richer recovery state is future work.

Secure future pipeline: authenticated seller requests an upload intent with validated product/variant ownership. Authorize quota and content policy before accepting bytes into a private Netlify Blobs quarantine key scoped to seller/product and generated server-side. Use expiring signed access only if supported by the selected upload API; otherwise stream through a bounded authenticated API. Never accept arbitrary object keys or fetch untrusted remote URLs.

Verify magic bytes and decode content, not just extensions or client MIME. Allow a narrow raster/video set, reject SVG/HTML and polyglots, cap total bytes, dimensions, duration, frame rate and decompressed pixels, scan for malware and strip EXIF/GPS. Process in a durable background job, create responsive derivatives, posters and video renditions, then mark ready atomically. Serve only reviewed ready assets through safe content types; use CSP and an approved CDN/domain allowlist. Limit retry and orphan lifetimes.

Deletion verifies seller/product ownership and order/legal retention. Soft-delete references first, enqueue idempotent object/derivative removal after grace period, audit who deleted it, and garbage-collect abandoned uploads with retries. Keep video bytes out of Postgres. A dedicated streaming/media provider may be required for transcoding; select and authorize it before implementing. Add captions/transcripts for spoken video before public content launch.
